# Levi Lian

Personal site at [levilian.com](https://levilian.com).

A single page. No framework UI, no loader, no sidebar. The writing is the site.

## Local

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Hosted on [Netlify](https://app.netlify.com/sites/levilian/deploys).

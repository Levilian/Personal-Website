On evaluation

I work on how we evaluate agents that do knowledge work — not chat, but the document, the workbook, the dossier left behind.

Most benchmarks still treat that labor like a quiz. A high score tells you almost nothing about whether the artifact would survive a reviewer. So we started writing down what a benchmark is actually claiming: which activity, under what conditions, scored on which work product.

The other half is the harness. Coding agents inherited git. Document agents inherited a pile of PDFs. StagedWorkspace is our attempt at a workspace-state contract: parsed search, native edits, and review diffs bound to the same version of the file. At Raycaster we run that idea in the open — traces, artifacts, rubrics, failures included. The score is only the index.

I help organize Eval Science, a small nonprofit symposium on how agents should be scientifically evaluated. Next gathering: New York, November 20.

StagedWorkspace: A Versioned Workspace for Knowledge-Work Agents

Hua, Na, Zhou, Kalose, Ayubcha, Lian

A workspace-state contract for mixed-format agents. Dual parsed/native access is the strongest setting on every model we tested; on OfficeQA Pro and APEX-Agents it moves the score by several points, and reviewable diffs help on file-editing tasks. Workspace state is the experimental variable.

2026 · arXiv 2605.23262

Designing Benchmarks for Knowledge Work

Hua, Na, Ayubcha, Lian

Four fields for a work-centered benchmark: represented activity, tested setting, required work product, evaluated result. We derive eighteen work activities from O*NET and read GDPval, OfficeQA Pro, and APEX-SWE through that lens — so a score can only claim the work it actually measured.

Harness

The product and the benchmark share a spine: a document-native environment, a rubric that inspects the artifact, and a run you can open. Published evaluations include the misses on purpose.

  • Public evals tasks, traces, scored files
  • Methodology evaluation as an evidence system
  • Environments reproducible work, not proxy actions
